Lógica y Estructuras Discretas

Instrucciones

Ingresa las premisas y la conclusión usando las letras p, q, r.

  • Usa and para conjunción (Y).
  • Usa or para disyunción (O).
  • Usa not para negación (NO).
  • Usa → para implicación (Si... entonces...).
  • Usa paréntesis ( ) para agrupar proposiciones compuestas.

Ejemplo: (p → q) and (q → r)

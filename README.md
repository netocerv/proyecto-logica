## Descripción
Programa que determina si un argumento lógico es válido. Permite ingresar hasta 3 premisas y una conclusión con las proposiciones `p`, `q`, `r` y los operadores `and`, `or`, `not` y `→`.

Incluye:
- Pestaña de **Validador** con botón de **Random**.
- Pestaña de **Tablas de Verdad** con todas las combinaciones.
- Resultados visuales con colores (verde = válido, rojo = no válido).

## Instrucciones de Uso
1. Abre `index.html` en tu navegador.
2. Ingresa las premisas y la conclusión.
3. Usa `and`, `or`, `not`, `→` y paréntesis.
4. Presiona **Validar Argumento**.
5. Usa **🎲 Random** para ejemplos aleatorios.
6. Cambia a **Tablas de Verdad** para ver las tablas completas.

## Ejemplos
- Válido: P1: `(p → q)`, P2: `p`, C: `q`
- No válido: P1: `(p → q)`, P2: `not p`, C: `q`
